Нефростома (норма)
📍 Локализация
В проекции левой/правой поясничной области (анатомическая зона расположения почки) определяется чрескожный нефростомический дренаж. Катетер фиксирован к коже липким пластырем / шовным материалом, положение его визуально не изменено.
🔍 Данные осмотра
  • Повязка в области стомы сухая, чистая, промокания мочой нет.
  • Кожные покровы вокруг места выхода дренажа не изменены: гиперемии, отека, инфильтрации, гнойного или серозного отделяемого не отмечается (признаки воспаления отсутствуют).
  • Послеоперационная рана (место пункции) без признаков мацерации, грануляций, налета фибрина.
🖐 Пальпаторные данные
  • Пальпация области нефростомы и окружающих мягких тканей поясничной области безболезненна.
  • Флюктуации, инфильтрации, крепитации в паранефральной области не определяется (признаков затека мочи, гематомы или абсцедирования нет).
  • При пальпации по ходу катетера болезненность отсутствует.
💧 Функциональный статус
  • Отток мочи по нефростомическому катетеру адекватный, мочеприемник заполняется порционно.
  • Моча прозрачная, соломенно-желтого цвета, без примесей крови, хлопьев фибрина, гноя.
  • Система герметична, признаков подтекания мочи мимо дренажа нет.
🚽 Мочеприемник
  • Мочеприемник прозрачный, герметичный.
  • Заполнен мочой на ___ мл.
  • Запаха мочи в помещении нет.
🌡️ Дополнительные данные
  • Лихорадки, озноба нет (признаков системной воспалительной реакции не выявлено).
  • Послеоперационный рубец (если имеется) без особенностей.
Несостоятельность нефростомы (нарушение фиксации, миграция, подтекание)
📍 Локализация
В проекции левой/правой поясничной области определяется чрескожный нефростомический дренаж. Наружная фиксация катетера ослаблена / отсутствует, возможно смещение дренажа кнаружи или внутрь.
🔍 Данные осмотра
  • Повязка в области стомы влажная, пропитана мочой.
  • Кожные покровы вокруг места выхода дренажа гиперемированы, отечны.
  • Признаки мацерации кожи (размягчение, покраснение, возможны эрозии и изъязвления).
  • Отделяемое из раны: серозное / гнойное / с примесью мочи.
  • Возможно наличие грануляций или налета фибрина в области стомы.
🖐 Пальпаторные данные
  • Пальпация области нефростомы болезненна.
  • Возможно наличие инфильтрации мягких тканей вокруг дренажа.
  • Флюктуация (признак скопления жидкости/гноя) в паранефральной области может определяться / не определяется.
  • При пальпации по ходу катетера — умеренная болезненность.
💧 Функциональный статус
  • Отток мочи по нефростомическому катетеру снижен / отсутствует.
  • Мочеприемник пуст / заполняется незначительно.
  • Отмечается подтекание мочи мимо дренажа на повязку и кожу.
  • Характер мочи: может быть мутная, с хлопьями, с примесью крови (признак воспаления или травмы).
  • При попытке аспирации шприцем — моча не поступает / поступает в малом количестве.
🌡️ Дополнительные данные
  • Возможна субфебрильная / фебрильная температура, озноб (признаки системной воспалительной реакции).
  • Пациент может предъявлять жалобы на боли в поясничной области.
Окклюзия нефростомы (закупорка дренажа, отсутствие оттока мочи)
📍 Локализация
В проекции левой/правой поясничной области определяется чрескожный нефростомический дренаж. Катетер фиксирован к коже удовлетворительно, положение его визуально не изменено.
🔍 Данные осмотра
  • Повязка в области стомы сухая, чистая, промокания мочой нет!
  • Кожные покровы вокруг места выхода дренажа не изменены (признаков воспаления нет).
  • Важно: Отсутствие подтекания мочи при отсутствии оттока по дренажу указывает на окклюзию (закупорку) катетера.
🖐 Пальпаторные данные
  • Пальпация области нефростомы может быть умеренно болезненной.
  • При глубокой пальпации в поясничной области — возможно напряжение мышц.
  • Флюктуации, инфильтрации, крепитации в паранефральной области может не быть / может определяться гидронефроз.
💧 Функциональный статус
  • Отток мочи по нефростомическому катетеру отсутствует (мочеприемник пуст).
  • При попытке аспирации шприцем — моча не поступает, ощущается выраженное сопротивление.
  • Промывание катетера физиологическим раствором затруднено или невозможно (раствор не проходит / идет обратным током).
  • Характер закупорки: возможно кровяными сгустками / гнойными массами / солями / детритом / сгустками слизи.
🌡️ Дополнительные данные
  • Лихорадка, озноб (признаки обструктивного пиелонефрита / уросепсиса).
  • Пациент предъявляет жалобы на интенсивные боли в поясничной области.
  • Возможны тошнота, рвота (признаки интоксикации).
  • При длительной окклюзии возможно развитие гидронефроза, пионефроза, уросепсиса.
