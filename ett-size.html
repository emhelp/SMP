📏 Эндотрахеальная трубка

Калькулятор размера, глубины, манжеты и катетера для аспирации с учётом веса пациента

💡 Вес используется для коррекции диаметра: при низком весе (<55 кг у женщин, <65 кг у мужчин) выбирается нижняя граница, при высоком весе (>95 кг) — верхняя граница. При ожирении возможно увеличение диаметра на 0.5 мм.
ℹ️ Детям до 8 лет рекомендованы трубки без манжеты. Вес влияет на подбор диаметра по таблице + дополнительная коррекция при несоответствии веса возрасту (например, при ожирении диаметр может быть увеличен на 0.5 мм).
